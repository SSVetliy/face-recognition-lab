# face-recognition-lab

Учебный проект по распознаванию лиц на Python. От детекции до идентификации
в реальном времени с логированием визитов.

Проект построен как **лаборатория**: каждый этап — отдельный модуль, который
можно изучать и тестировать независимо.

## Что умеет

- **Детекция лиц** в реальном времени (SCRFD, insightface).
- **Извлечение эмбеддингов** — 512-мерных «отпечатков» лиц (ArcFace).
- **Усреднённые эталоны** — по нескольким фото человека строится один
  стабильный вектор, что даёт высокую точность идентификации.
- **Идентификация 1:N** — по лицу определяет, кто это, или помечает как
  `UNKNOWN`.
- **Логирование визитов** в CSV с антиспамом (cooldown).
- **Работа с камерой** — распознавание в реальном времени.

## Технологии

| Слой | Что используется |
|---|---|
| Язык | Python 3.10.11 |
| Детекция + распознавание | insightface (SCRFD + ArcFace) |
| Инференс | onnxruntime (CPU) |
| Компьютерное зрение | OpenCV |
| Числа | NumPy |

Модель: `buffalo_sc` — компактная, работает на CPU без GPU.

## Установка

### Требования

- **Windows 10/11** (проект тестировался на Windows; на Linux/macOS
  должно работать, но не проверялось).
- **Python 3.10.11** (другие версии не тестировались).
- **VS Code** или любой другой редактор.

### Шаги

1. **Клонируй репозиторий:**
   ```bash
   git clone git@github.com:SSVetliy/face-recognition-lab.git
   cd face-recognition-lab
   ```

2. **Создай виртуальное окружение:**
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. **Обнови pip:**
   ```powershell
   python -m pip install --upgrade pip
   ```

4. **Установи зависимости:**
   ```powershell
   pip install -r requirements.txt
   ```

5. **Установи insightface отдельно** (он не ставится через
   `requirements.txt` на Windows без компилятора C++):

   Скачай готовый `.whl`:
   [insightface-0.7.3-cp310-cp310-win_amd64.whl](https://github.com/Gourieff/Assets/raw/main/Insightface/insightface-0.7.3-cp310-cp310-win_amd64.whl)

   Положи файл в корень проекта и выполни:
   ```powershell
   pip install --no-deps insightface-0.7.3-cp310-cp310-win_amd64.whl
   ```

6. **Проверь установку:**
   ```powershell
   python -c "import numpy, onnx, onnxruntime, cv2, insightface; print('OK')"
   ```

**Примечание:** первый запуск любого скрипта с моделью скачает
`buffalo_sc` (~300 МБ) в `C:\Users\<user>\.insightface\models\`.
Это одноразово.

## Использование

### 1. Проверка детекции на камере

```powershell
python scripts/test_detection.py
```

Откроется окно, вокруг лиц — зелёные рамки с confidence. Выход — `ESC`.

### 2. Построение базы эталонов

Помести фото в `data/photos/<имя>/`, где `<имя>` — имя человека:

```
data/photos/
├── ivan/
│   ├── 1.jpg
│   ├── 2.jpg
│   └── 3.jpg
└── maria/
    ├── 1.jpg
    └── 2.jpg
```

**Рекомендации по фото:**
- 3–10 фото на человека.
- Разные ракурсы, освещение, выражения лица.
- Лицо должно быть крупным и в фокусе.

Затем:

```powershell
python scripts/build_base.py
```

База сохранится в `data/embeddings/base.npz`.

### 3. Тест идентификации на фото

Положи тестовые фото (не из папок людей) в корень `data/photos/`:

```powershell
python scripts/test_identification.py
```

Выведет таблицу: файл, лицо, предсказанное имя, расстояние.

### 4. Распознавание в реальном времени

```powershell
python scripts/run_recognition.py
```

- Зелёная рамка + имя — свой.
- Красная рамка + `UNKNOWN` — неизвестный.
- Визиты пишутся в `data/logs/visits.csv`.
- Повторный визит в течение 5 минут не логируется.

## Как это работает

1. **Детекция:** SCRFD находит все лица на кадре.
2. **Выравнивание:** по 5 ключевым точкам лицо приводится к стандартному виду.
3. **Эмбеддинг:** ArcFace превращает лицо в вектор из 512 чисел.
   У одного человека на разных фото векторы близки, у разных — далеки.
4. **Усреднение:** для каждого человека эмбеддинги его фото усредняются
   в один стабильный вектор.
5. **Сравнение:** косинусное расстояние между эмбеддингом запроса и
   эталонами. Ближайший эталон + порог → имя или `UNKNOWN`.

**Порог идентификации:** `0.50` (настраивается в `src/config.py`).

## Ограничения

- **CPU-only:** проект работает без GPU, но FPS ограничен (20–25 на
  современном CPU при 1280×720).
- **Windows-ориентирован:** установка `insightface` требует
  предварительно собранного `.whl`. На Linux/macOS можно поставить
  обычным `pip install insightface`, если есть компилятор.
- **Плохое освещение** снижает точность.
- **Сильные аксессуары** (солнечные очки, маски) мешают распознаванию.
- **Приватность:** не загружайте фото людей без их согласия.
